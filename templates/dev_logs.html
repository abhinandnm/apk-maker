Privacy Policy

Data Isolation & Privacy

All compilation builds run inside isolated sandboxed containers on our cloud server. Your source code and access keys are kept secure and separate from other operations.

Automatic Data Deletion

Your uploaded ZIP archives, cloned Git repositories, compilation log outputs, and generated APK files are hosted temporarily on the server and are automatically and permanently deleted 5 hours after creation.

No Personal Tracking

We do not collect or log personal user details, IP addresses, or project data beyond the active lifecycle of your build compilation.
